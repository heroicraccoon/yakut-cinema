# Якутское кино

Каталог якутских фильмов с возможностью поиска, сортировки и добавления в вишлист.

## О проекте
Этот сайт создан для популяризации якутского кинематографа. Здесь собраны лучшие картины, чтобы каждый мог открыть для себя это уникальное направление в кино.

## Функционал
- Поиск по названию фильма.
- Сортировка по году выпуска.
- Кнопка «Хочу посмотреть» для формирования личного вишлиста.
- Адаптивная верстка (сайт удобно смотреть и на компьютере, и на телефоне).

## Как запустить локально
Если ты разработчик и хочешь запустить проект у себя на компьютере:
1. Клонируй репозиторий: `git clone https://github.com/heroicraccoon/yakut-cinema.git`
2. Открой файл `index.html` в любом браузере.
